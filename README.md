# Heart Risk Predictor

Portfolio site for a Heart Disease Prediction project (Pandas, NumPy, machine learning, Flask).

Four modules: Overview, Pipeline, Predictor, Recommendations.

The Predictor page scores inputs with a simple illustrative formula in the browser. It does not run the trained model and is not medical advice.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server 8000` and visit http://localhost:8000.

## Deploy
Static site, no build step. Import this repository in Vercel with the Other framework preset and leave the build command and output directory empty.
